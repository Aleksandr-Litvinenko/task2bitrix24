## 2026-08-02 — предполётная проверка настройки

**Что добавлено**

- `tools/preflight.php` — диагностика конфигурации из командной строки.
  Проверяет всё, что перечислено в `docs/DEPLOYMENT.md`:
  - версию PHP и расширения `zip`, `curl`, `json`, `mbstring`, `openssl`;
  - откуда берутся настройки — `config.local.php` или переменные окружения;
  - формат `BITRIX_WEBHOOK` и то, что пароль панели сменён с `change-me`;
  - существование и права на запись у папки снимков дашборда;
  - заданы ли учётные данные OData для кнопок УНФ;
  - с флагом `--online` — реальные права вебхука по каждому используемому
    методу (`user.get`, `tasks.task.list`, `sonet_group.get`,
    `crm.company.list`, `task.elapseditem.getlist`) и доступность OData УНФ.

**Что изменено**

- `docs/DEPLOYMENT.md` — раздел «Проверка настройки» перед локальным запуском.
- `README.md` — команда проверки в «Запуске».

**Зачем**

Приложение конфигурируется девятью с лишним обязательными значениями, и почти
каждое проявляет себя только в момент использования: нет прав на
`task.elapseditem.getlist` — узнаёшь при выгрузке Excel, папка `data/` не пишется —
при обновлении дашборда, не сменён пароль по умолчанию — не узнаёшь никогда.
Проверка собирает всё это в один запуск за пару секунд.

Отдельно разведены блокирующие проблемы и предупреждения. Нет прав на
`sonet_group.get` — это предупреждение, а не отказ: доска продолжит работать,
просто проекты получат имена вида «Проект #123», как и написано в README.
Нет учётных данных УНФ — тоже предупреждение: без них не работают только две
кнопки, всё остальное работает.

**Совместимость**

Существующий код не тронут. Скрипт подключает `lib.php` (в нём только
определения функций) и ничего не пишет: в онлайн-режиме выполняются
только читающие запросы, документы в УНФ не создаются. Запуск из веба
заблокирован — только CLI.
