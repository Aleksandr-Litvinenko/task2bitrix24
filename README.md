# taskCRM

Веб-панель поверх Битрикс24: закрытые часы сотрудников, доска задач по проектам и дашборд-рейтинг.

Развитие проекта [task2bitrix24](https://github.com/Aleksandr-Litvinenko/task2bitrix24): сохранён весь функционал «Закрытых часов» и добавлена верхняя навигация с четырьмя вкладками.

## Вкладки

- **Основной** — выгрузка закрытых часов в Excel и две кнопки УНФ: «создать Учеты времени» (документ за первую полную неделю месяца, время по дням заполняется «с»/«по», комментарий с тегом `#Загружено_task2` и часами) и «создать Задания на работу» (на 1-е число следующего месяца, план = факт +10%). Документы проводятся автоматически (`UNF_TIME_POST_DOCUMENTS`).
- **Задачи** — доска-водопад: колонки-проекты (рабочие группы Битрикс) листаются вправо, задачи внутри листаются вниз. Две вкладки: «Активные задачи» и «Закрытые задачи» (за выбранный месяц). Показываются задачи всей команды (`REPORT_USER_IDS`).
- **Дашборд** — рейтинг сотрудников по закрытым часам за месяц. Снимок сохраняется по каждому месяцу в `data/dashboard-YYYY-MM.json` и обновляется автоматически при выгрузке Excel и при создании учётов времени в УНФ, а также вручную кнопкой «Обновить за этот месяц».
- **ХОЧУ ТАКЖЕ** — ведёт на телеграм-канал автора (`https://t.me/kodar1c`).

## Отчёт по выбранным компаниям

На «Главной» под выбором месяца есть форма «Отчёт по выбранным компаниям»: тот же период, но только задачи выбранных клиентов, и в файле будет единственный лист «Все задачи». Выбранные компании висят чипами сверху и убираются крестиком; в выпадающем списке «Добавить компанию…» остаются только невыбранные. Целевые клиенты (`REPORT_DEFAULT_COMPANY_IDS`: Инситех, Инситех-Девелопмент, Реалток, Ройал Рэббит, Лактех) добавлены сразу. Справочник CRM кешируется в `data/companies.json` на сутки.

В детальных листах Excel (по каждому сотруднику и «Все задачи») есть колонка **«Дата списания»** — когда часы фактически потрачены (`DATE_START` записи учёта времени).

## Проверка корректности заполнения задач

Кнопка на «Главной» открывает `quality.php` — проверку задач, закрытых в выбранном месяце (`REAL_STATUS` 4/5). Результат показывается на экране и выгружается в Excel (листы «Свод» и «Задачи с замечаниями»). Последний результат кешируется в `data/quality-YYYY-MM.json`, поэтому выгрузка Excel не опрашивает Битрикс повторно.

Красный флаг — задачу нельзя выставить в счёт как есть:

- не списаны часы;
- нет результата задачи или в нём нет даты выполнения работ;
- месяц в результате не совпадает с месяцем закрытия;
- не заполнен элемент CRM;
- не заполнен проект у ключевого клиента (`QUALITY_RED_FLAG_COMPANY_IDS` / `..._NAMES`: Инситех, Инситех-Девелопмент, Ройал Рэббит, Лактех). У остальных компаний проект не проверяется.

Жёлтое предупреждение:

- результат длиннее `QUALITY_RESULT_LEN_WARN` (300) символов;
- дата выполнения работ записана не в формате `(дата выполнения работ ДД.ММ.ГГГГ)`.

## Роли и администрирование

Кнопка «Администрирование» в «Полезных кнопках» (видна только администратору) открывает админ-панель: добавление пользователей с логином/паролем и ролью. Пользователи хранятся в `data/users.json` (пароли — `password_hash`), учётка из `APP_AUTH_USER`/`APP_AUTH_PASSWORD` — всегда администратор.

| Роль | Просмотр | Excel | Документы УНФ | Админка | Данные |
|---|---|---|---|---|---|
| Администратор | да | да | да | да | открытые |
| Сотрудник | да | да | нет | нет | открытые |
| Внешний | да | нет | нет | нет | зашифрованные (имена, названия, часы) |

## Запуск

```sh
cp config.local.example.php config.local.php
```

Заполните `LOCAL_BITRIX_WEBHOOK`, `LOCAL_APP_AUTH_PASSWORD` и, если нужна кнопка УНФ, `LOCAL_UNF_ODATA_USER` / `LOCAL_UNF_ODATA_PASSWORD`.

Проверить, что всё настроено (ничего не меняет, только читает):

```sh
php tools/preflight.php
```

Из папки проекта:

```sh
php -S 127.0.0.1:8080
```

Открыть `http://127.0.0.1:8080/`. Логин по умолчанию: `admin`.

## Настройки

Можно переопределить через переменные окружения:

```sh
BITRIX_WEBHOOK="https://<portal>.bitrix24.ru/rest/<user-id>/<webhook-code>/" \
APP_AUTH_USER="admin" APP_AUTH_PASSWORD="<strong-password>" \
php -S 127.0.0.1:8080
```

Доска «Задачи» и дашборд используют те же настройки и список сотрудников (`REPORT_USER_IDS`). Доске нужен доступ webhook к `tasks.task.list`, `sonet_group.get`, `user.get` и `crm.company.list`. Если у webhook нет прав на `sonet_group.get`, проекты в колонках получат имена вида `Проект #<id>`, но доска продолжит работать.

Папка `data/` должна быть доступна на запись веб-серверу — там хранятся снимки дашборда.

## Состав файлов

- `index.php`, `tasks.php`, `dashboard.php` — три вкладки;
- `report.php` — выгрузка Excel; `unf_time.php` — создание документов УНФ; `dashboard_refresh.php` — ручное обновление дашборда (POST);
- `partials/head.php`, `partials/foot.php` — общая разметка и навигация; `effects.js` — фоновый курсор-трейл;
- `lib.php` — Битрикс REST, отчёт, доска, дашборд и генерация `.xlsx`; `unf.php` — интеграция с УНФ (OData);
- `auth.php`, `config.php`, `config.local.example.php`, `style.css`.

## Отчёт «Закрытые часы»

Берутся задачи, закрытые в окне ±`REPORT_CLOSED_WINDOW_MONTHS` (по умолчанию 2) месяца вокруг отчётного, со статусом `REPORT_CLOSED_STATUSES` (по умолчанию только `5` — «Завершена»; «условно завершена» ждёт одобрения и в счёт не идёт). Затем включаются только задачи, где дата в результате выполнения попадает в выбранный месяц. Списанное время суммируется через `task.elapseditem.getlist` по списку сотрудников.

В Excel создаются:

- лист `Свод`;
- лист `Все задачи` сразу за сводом;
- отдельный лист по каждому сотруднику с детализацией задач и часов.

Лист `Все задачи`: поля задачи заполнены в каждой строке для фильтров, задачи отделены рамками и чередующейся заливкой, рядом с `Затрачено` есть `Итого` по задаче.
