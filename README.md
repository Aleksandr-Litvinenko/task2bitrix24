# task2bitrix24

Веб-сервис для формирования Excel-отчёта по закрытым часам сотрудников из Bitrix24.

Сервис открывает простую веб-форму выбора месяца и года, получает данные из Bitrix24 через REST webhook и отдаёт `.xlsx` на скачивание.

## Что формирует Excel

- `Свод`: список сотрудников, закрытые часы и количество задач.
- Отдельная вкладка на каждого сотрудника: задачи и списания времени по сотруднику.
- `Все задачи`: общий лист со всеми строками списаний, фильтрами, дублированными полями задачи для корректной фильтрации, чередующейся заливкой задач и итогом часов по задаче.

## Быстрый локальный запуск

```sh
cp task2/config.local.example.php task2/config.local.php
```

Заполните `task2/config.local.php` реальным Bitrix24 webhook и паролем для Basic Auth, затем запустите:

```sh
php -S 127.0.0.1:8080 -t task2
```

Откройте `http://127.0.0.1:8080/`.
