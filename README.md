# taskCRM

Веб-панель поверх Битрикс24: закрытые часы сотрудников, доска задач по проектам и дашборд-рейтинг.

Развитие проекта [task2bitrix24](https://github.com/Aleksandr-Litvinenko/task2bitrix24): сохранён весь функционал «Закрытых часов» и добавлена верхняя навигация с четырьмя вкладками.

## Вкладки

- **Основной** — выгрузка закрытых часов в Excel и кнопка «Создать учёты времени в нашей рабочей УНФ» (как раньше).
- **Задачи** — доска-водопад: колонки-проекты (рабочие группы Битрикс) листаются вправо, задачи внутри листаются вниз. Две вкладки: «Активные задачи» и «Закрытые задачи» (за выбранный месяц). Показываются задачи всей команды (`REPORT_USER_IDS`).
- **Дашборд** — рейтинг сотрудников по закрытым часам за месяц. Снимок сохраняется по каждому месяцу в `data/dashboard-YYYY-MM.json` и обновляется автоматически при выгрузке Excel и при создании учётов времени в УНФ, а также вручную кнопкой «Обновить за этот месяц».
- **ХОЧУ ТАКЖЕ** — ведёт на телеграм-канал автора (`https://t.me/kodar1c`).

## Запуск

```sh
cp config.local.example.php config.local.php
```

Заполните `LOCAL_BITRIX_WEBHOOK`, `LOCAL_APP_AUTH_PASSWORD` и, если нужна кнопка УНФ, `LOCAL_UNF_ODATA_USER` / `LOCAL_UNF_ODATA_PASSWORD`.

Из папки проекта:

```sh
php -S 127.0.0.1:8080
```

Открыть `http://127.0.0.1:8080/`. Логин по умолчанию: `admin`.

## Настройки

Можно переопределить через переменные окружения:

```sh
BITRIX_WEBHOOK="https://<portal>.bitrix24.ru/rest/<user-id>/<webhook-code>/" \
APP_AUTH_USER="admin" APP_AUTH_PASSWORD="<strong-password>" \
php -S 127.0.0.1:8080
```

Доска «Задачи» и дашборд используют те же настройки и список сотрудников (`REPORT_USER_IDS`). Доске нужен доступ webhook к `tasks.task.list`, `sonet_group.get`, `user.get` и `crm.company.list`. Если у webhook нет прав на `sonet_group.get`, проекты в колонках получат имена вида `Проект #<id>`, но доска продолжит работать.

Папка `data/` должна быть доступна на запись веб-серверу — там хранятся снимки дашборда.

## Состав файлов

- `index.php`, `tasks.php`, `dashboard.php` — три вкладки;
- `report.php` — выгрузка Excel; `unf_time.php` — создание документов УНФ; `dashboard_refresh.php` — ручное обновление дашборда (POST);
- `partials/head.php`, `partials/foot.php` — общая разметка и навигация; `effects.js` — фоновый курсор-трейл;
- `lib.php` — Битрикс REST, отчёт, доска, дашборд и генерация `.xlsx`; `unf.php` — интеграция с УНФ (OData);
- `auth.php`, `config.php`, `config.local.example.php`, `style.css`.

## Отчёт «Закрытые часы»

Берутся задачи, закрытые в выбранном месяце с запасом 7 дней до начала и 7 дней после конца месяца, оставляются `REAL_STATUS` `4` и `5`, затем включаются только задачи, где дата в результате выполнения попадает в выбранный месяц. Списанное время суммируется через `task.elapseditem.getlist` по списку сотрудников.

В Excel создаются:

- лист `Свод`;
- отдельный лист по каждому сотруднику с детализацией задач и часов;
- лист `Все задачи`: поля задачи заполнены в каждой строке для фильтров, задачи отделены рамками и чередующейся заливкой, рядом с `Затрачено` есть `Итого` по задаче.
